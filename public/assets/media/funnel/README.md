# Funnel media (served)

Files here are static assets for funnel pages. **URL base:** `/assets/media/funnel/`

Example in a template or script:

```html
<video src="/assets/media/funnel/example.webm" …></video>
```

Do not put Facebook-only ad creatives here—use `creative/facebook-ads/`. See `docs/CREATIVE-MEDIA.md`.
